# TechSchool UX/UI Design Camp

가상의 UX/UI 디자인 캠프를 홍보하기 위한 반응형 랜딩페이지입니다.

## 프로젝트 목적

HTML, CSS, JavaScript를 활용하여
실제 서비스 형태의 랜딩페이지를 구현하고
Responsive Web 및 사용자 인터랙션을 학습하는 것을 목표로 했습니다.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- jQuery

## 주요 기능

- Responsive Layout
- Sticky Navigation
- FAQ Accordion
- 상담 신청 Form
- Client-side Form Validation
- Modal
- Smooth Scroll

## 주요 학습 내용

- Semantic HTML
- CSS Flexbox / Grid
- Responsive Web
- DOM Manipulation
- Event Handling
- Form Validation
